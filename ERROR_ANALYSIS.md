## Visual review and annotation limits

Visual inspection of receipt images against committed predictions and frozen annotations; independent of LLM judge

Selected examples reviewed, not a complete manual relabeling. Metrics remain unchanged against official annotations.

### cord_held_out_000: reasoning

Status: visually_confirmed. Backends: qwen, docling_text_llm.

Printed amounts use dot grouping (60.000 and 5.455), while returned numeric values are 60.0 and 5.455. The scorer expects 60000 and 5455; these are magnitude errors, not mere JSON formatting differences. The judge incorrectly described those differences as harmless formatting.

### cord_held_out_000: annotation_gap

Status: possible_annotation_gap. Backends: gemini.

The image visibly contains two 60.000 amounts on the item row, but the CORD parse does not annotate menu.unitprice. A prediction of 60000 is scored as an extra against the frozen annotations; the image does not justify treating it as a proven hallucination. The column heading is not visible, so exact role remains uncertain.

### cord_held_out_001: reasoning

Status: visually_confirmed. Backends: gemini, qwen, docling_text_llm.

The receipt displays description/amount rows and TOTAL/CASH 91000, with no printed quantity or unit-price column and no separate subtotal. All three adapters infer quantity 1, reuse line amounts as unit prices, and copy total into subtotal. This is a schema/abstention limitation as well as unsupported reasoning.

### cord_held_out_002: layout

Status: visually_confirmed. Backends: gemini, qwen.

The receipt has one numbered drink and an indented Coconut Jelly add-on with its own amount but no separate quantity; TOTAL ITEMS is one. Both vision adapters promote the add-on to a separate main line with quantity one. The benchmark maps main menu fields and excludes add-on labels, so this is a parent/child layout and schema-mapping limitation.

### cord_held_out_014: OCR

Status: visually_confirmed. Backends: qwen.

The printed rows read Mushroom Soup and Chamomile. Qwen returns Nushroom Soup and Chamonile, character substitutions that disagree with both the visible receipt and the frozen labels. The classification identifies transcription errors in the pipeline; it does not isolate whether Docling or the VLM caused them.

### cord_held_out_013: schema

Status: visually_confirmed_schema_ceiling. Backends: gemini, qwen, docling_text_llm.

The receipt repeats the same base amount in TOTAL and DPP. CORD annotates both as subtotal values. The original label adapter incorrectly nested this list; the corrected adapter preserves two values. The output schema has a scalar subtotal and cannot represent both annotated regions, so multiset scoring necessarily records a missed occurrence. This is a representation ceiling rather than invalid returned JSON.
